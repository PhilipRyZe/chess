So geht's

Spiel starten

  1. Klicke auf Spielen und dann auf Spiel erstellen.
  2. Schicke den Code oder den Link an deinen Gegner.
  3. Dein Gegner öffnet den Link oder gibt den Code unter Spiel beitreten ein.
  4. Sobald beide verbunden sind, geht es los. Weiß beginnt.

Ziehen

Klicke auf eine Figur. Alle möglichen Züge werden markiert. Klicke dann auf das Zielfeld. Rochade, en passant und Umwandlung funktionieren automatisch. Bei einer Umwandlung wählst du die neue Figur aus.

Neue Partie

Mit Neue Partie startet ihr direkt noch einmal, die Farben werden dabei getauscht.

Design anpassen

Unter Design stellst du Farbschema, Schachbrett, Figurenfarben und Figurenstil ein. Die Vorschau zeigt sofort, wie es aussieht. Das gilt nur für dich, dein Gegner sieht sein eigenes Design.

Verbindung

Im selben WLAN klappt die Verbindung fast immer. Zwischen verschiedenen Netzen kann sie bei manchen Routern scheitern. Wenn die Verbindung abbricht, lade die Seite neu und erstellt ein neues Spiel.

Über diese Seite

Ein kleines Schachspiel für zwei, gebaut als Hobbyprojekt. Es gibt keine Registrierung, keine Werbung und keine Kosten.

Datenschutz

Die Züge gehen direkt von Browser zu Browser. Es gibt keinen eigenen Server und es wird nichts gespeichert. Nur für den Verbindungsaufbau wird der kostenlose Vermittlungsdienst von PeerJS genutzt, der dabei die IP-Adressen der beiden Spieler sieht.

Technik

Die Regeln kommen von chess.js, die Verbindung von PeerJS (WebRTC). Beides wird über das öffentliche CDN geladen.
